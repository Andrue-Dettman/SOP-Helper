# Labeling accepted stock

Fictional demonstration material. This is not an employer procedure or certified operational guidance.

## Before you start {#preparation}

[prerequisite:label-pre-01 steps=*] Use stock already accepted under the receiving procedure.

## Match and apply labels {#apply-label}

[warning:label-stop-01 steps=label-01] If the part ID cannot be confirmed, stop. Do not guess a label. Ask the demo supervisor.

1. [step:label-01] Match the accepted item to its canonical part ID in the sample catalog.
2. [step:label-02] Copy the confirmed part ID onto one sample label per storage container.
3. [step:label-03] Attach each label so it can be read without moving the contents.
4. [step:label-04] Compare the attached label with the sample catalog before completing the task.

## Terms {#terms}

Canonical part ID: the unique identifier assigned to a fictional part.
