# Counting stock

Fictional demonstration material. This is not an employer procedure or certified operational guidance.

## Before you start {#preparation}

[prerequisite:count-pre-01 steps=*] Use the sample count sheet for the selected part and location.

## Count and record {#count-and-record}

[warning:count-stop-01 steps=*] If a label is missing or the counts disagree, do not change a stock total or guess. Report the uncertainty to the demo supervisor.

1. [step:count-01] Match the part and location labels to the sample count sheet.
2. [step:count-02] Count whole units once and write the observed count on the sheet.
3. [step:count-03] Count the same units a second time and record that count separately.
4. [step:count-04] Report both counts and any difference to the demo supervisor.

## Terms {#terms}

Observed count: the number written during a count, which does not itself update inventory.
